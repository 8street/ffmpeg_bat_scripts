# VIDEO AUDIO CONVERTER

There some .bat scripts for ffmpeg. Drag and drop the video files to the required script.

## Folder ffmpeg
Put ffmpeg.exe ffplay.exe ffprobe.exe here.

## Folder reserve
Some reserve files there. To use them you must move the script to the main folder.

## Folder resources
Service script files there.

## AV1
Convert video to AV1 format. More compressed and better quality. Newer.

## VP9
Convert video to VP9 format. Less compressed and faster to decode. Older than AV1.

## Concat
It is possible to merge several files into one.

## Cut Video
Cut video without coding. Cuting settings in the .bat file.

## FLAC
Convert audio in videofile to FLAC format.

## AAC
Convert audio in videofile to AAC 320kbps.

## Add MixAudio
Add an audio track to the video and mix it with the existing track. Mixer settings in .bat. The old track is saved as a secondary track.

## Add Date
Add date to filename.

## Rotate
Rotate the video clockwise by 90 degrees.

## Settings
Various converter settings in the .bat file. There possible enable test conversion for fast results.

## Encoders
Displays a list of available encoders.

## Probe
Pribing video with ffprobe.exe.
